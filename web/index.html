S SIMAC Prep TPE / PME

Préparez vos rendez-vous de vente en 20 minutes

Un outil gratuit, sans compte, qui applique la méthode SIMAC et le profil SONCAS. Vos données restent dans votre navigateur.

  1. Offre — décrivez votre produit, joignez une plaquette : l’IA remplit la fiche et note la maturité (1-5).
  2. Client — qui vous allez voir (jusqu’à 3 personnes), dans quel cadre : fiche avec faits sourcés, hypothèses et questions de découverte.
  3. Persona — motivations SONCAS notées 1-3 pour chaque personne, tensions entre elles, un seul message principal calé sur qui décide.
  4. SIMAC — le déroulé du rendez-vous, prix en dernier, objections préparées.
  5. Suivi — racontez le rendez-vous : mail de suivi centré sur l’action convenue, mémoire CSV.

Il vous faut une clé d’IA gratuite (Groq, Gemini, Mistral, OpenRouter) ou Ollama en local — à coller dans Réglages — ou le mode démo pour découvrir.

Clé gratuite = pour tester et pour les données publiques. Sites web, plaquettes, fiches d’entreprise, profils publics : utilisables tels quels. Avec une offre gratuite, le fournisseur peut réutiliser ce que vous envoyez : nous déconseillons d’y mettre des données non publiques (mails reçus, devis, notes internes, coordonnées personnelles). Pour ces données, utilisez une clé d’une offre payante souscrite chez votre fournisseur d’IA (Groq, Gemini, Mistral, OpenRouter — rien n’est payé à AVApmo, l’outil reste gratuit) dont les conditions excluent l’usage de vos données, ou Ollama en local : rien ne sort de votre ordinateur.
